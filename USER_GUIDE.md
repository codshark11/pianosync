## Getting Started

### Installation

1. Download PianoSync from [Google Play Store](https://play.google.com/store/apps/details?id=io.scoreflow.app)
2. Open the app after installation
3. Grant necessary permissions when prompted

### First Time Setup

1. **Connect Your Piano** (Optional)
   - Connect your MIDI keyboard via USB or Bluetooth
   - The app will automatically detect connected devices
   - You can also use the virtual keyboard if you don't have a physical piano

2. **Import Your First MIDI File**
   - Tap the "Import MIDI" card on the home screen
   - Select a MIDI file from your device
   - The file will appear in your library

3. **Start Practicing**
   - Tap on a MIDI file to open the player
   - Press play to start
   - Follow the falling notes on screen

## Basic Features

### Home Screen

The home screen is your main hub for managing MIDI files and accessing features.

**Features:**
- **Import MIDI**: Tap to import new MIDI files
- **MIDI File Cards**: Display your imported files with:
  - File name
  - BPM (beats per minute)
  - Last played date
  - Recent performance scores
- **Navigation Icons**:
  - Progress Tracking: View your practice statistics
  - Settings: Configure app preferences
  - Piano Connection Status: Shows if your piano is connected

### MIDI Player Screen

The main practice interface with all playback controls.

**Visual Elements:**
- **Falling Notes**: Notes fall from top to bottom
- **Piano Keyboard**: Virtual keyboard at the bottom
- **Sheet Music**: Optional sheet music display
- **Play Line**: Horizontal line where notes should be played

**Playback Controls:**
- **Play/Pause**: Start or pause playback
- **Stop**: Stop and reset to beginning
- **Restart**: Jump back to the start
- **BPM Control**: Adjust playback tempo
- **Loop Toggle**: Enable/disable looping
- **Hand Mode**: Select left hand, right hand, or both

**Practice Features:**
- **Recording**: Record your performance
- **Metronome**: Visual and audio metronome
- **Score Display**: Real-time accuracy score
- **Statistics**: Notes hit/missed counts

### Progress Tracking

View detailed statistics about your practice sessions.

**Statistics Shown:**
- Total practice sessions
- Average score
- Best score
- Practice time
- Score progress over time
- Recent practice sessions

**Features:**
- View statistics for individual pieces
- View overall statistics
- See score trends with charts
- Review recent performances

### Settings

Customize your practice experience.

**Gameplay Settings:**
- **Difficulty Level**: Easy, Medium, Hard, Expert
  - Easy: Generous timing window, key names shown
  - Medium: Balanced timing window
  - Hard: Precise timing required
  - Expert: Professional-level precision
- **Show Key Names**: Display note names on keys (Easy mode only)

**Audio Settings:**
- **Playback Sync Offset**: Adjust if notes aren't synchronized
  - Recommended: 2000ms for tablets, 4500ms for phones
- **Metronome Volume**: Control metronome volume (0-100%)

## Advanced Features

### Recording Your Performance

1. **Start Recording**
   - Tap the record button before or during playback
   - Recording indicator will appear
   - Play along with the song

2. **Stop Recording**
   - Tap stop when finished
   - Recording automatically stops at song end
   - Your performance is saved automatically

3. **View Recordings**
   - Go to Progress Tracking
   - Select a piece
   - Scroll to "MIDI Recordings" section
   - Tap a recording to play it back

4. **Export Recordings**
   - In Progress Tracking, select a recording
   - Tap "Export" to save as MIDI file
   - Share or use in other applications

### Hand Mode Practice

Practice specific hands to improve technique.

**Modes:**
- **Both Hands**: Full song with all notes
- **Left Hand Only**: Practice left hand parts
- **Right Hand Only**: Practice right hand parts

**Usage:**
- Select hand mode before or during playback
- Notes for the selected hand will be displayed
- Audio playback matches the selected mode

### BPM Control

Adjust tempo to match your skill level.

**Features:**
- View original BPM from MIDI file
- Adjust BPM to slow down or speed up
- Changes apply immediately
- BPM is saved per file

**Tips:**
- Start slow to learn the notes
- Gradually increase speed as you improve
- Use original BPM as a goal

### Loop Mode

Practice specific sections repeatedly.

**How to Use:**
1. Enable loop mode
2. Play the section you want to practice
3. The song will automatically loop
4. Disable to play through the entire song

**Benefits:**
- Focus on difficult sections
- Build muscle memory
- Improve accuracy

### Metronome

Keep steady tempo while practicing.

**Features:**
- Visual metronome indicator
- Audio tick/tock sounds
- Adjustable volume
- Synchronized with playback

**Usage:**
- Metronome appears during playback
- Adjust volume in Settings
- Use to maintain consistent tempo

   - Finally combine both hands

## Troubleshooting

### Piano Connection Issues

**Problem**: Piano not detected

**Solutions:**
- Ensure piano is powered on
- Check USB/Bluetooth connection
- Restart the app
- Try disconnecting and reconnecting
- Check if your device supports MIDI (Android 6.0+)
- Use Test Mode if you don't have a physical piano

**Problem**: Notes not registering

**Solutions:**
- Check piano connection status indicator
- Verify MIDI channel settings on piano
- Try restarting the app
- Check if piano is in the correct mode

### Playback Issues

**Problem**: Audio and visual notes not synchronized

**Solutions:**
- Go to Settings → Audio
- Adjust "Playback Sync Offset"
- Try recommended values:
  - Tablets: 2000ms
  - Phones: 4500ms
- Fine-tune until synchronized

**Problem**: No audio playback

**Solutions:**
- Check device volume
- Verify MIDI file is valid
- Try restarting playback
- Check if hand mode is filtering all notes

**Problem**: Playback stuttering

**Solutions:**
- Close other apps
- Restart device
- Check available storage
- Try a different MIDI file

### Performance Issues

**Problem**: App is slow or laggy

**Solutions:**
- Close other apps
- Restart the app
- Clear app cache (Settings → Apps → PianoSync → Clear Cache)
- Restart device

**Problem**: Notes not appearing

**Solutions:**
- Check if hand mode is filtering notes
- Verify MIDI file has notes in selected range
- Try switching hand modes
- Restart playback

### File Import Issues

**Problem**: Can't import MIDI file

**Solutions:**
- Verify file is a valid MIDI file (.mid, .midi)
- Check file permissions
- Try selecting file from different location
- Ensure file isn't corrupted

**Problem**: Imported file doesn't play

**Solutions:**
- Verify file is complete
- Try a different MIDI file
- Check if file has notes
- Restart the app

## FAQ

### General Questions

**Q: Do I need a physical piano to use PianoSync?**
A: No, you can use the virtual keyboard. However, a physical MIDI keyboard provides a better practice experience.

**Q: What MIDI files are supported?**
A: Standard MIDI files (.mid, .midi) are supported. The app works best with files containing piano music.

**Q: Can I use PianoSync offline?**
A: Yes, PianoSync works completely offline. No internet connection is required.

**Q: Does PianoSync collect my data?**
A: No, PianoSync collects no personal data. All data is stored locally on your device. See [PrivacyPolicy.md](PrivacyPolicy.md) for details.

### Practice Questions

**Q: How is my score calculated?**
A: Score is based on timing accuracy. Notes played at the correct time count as hits, others count as misses. Score = (Notes Hit / Total Notes) × 100.

**Q: What's the difference between difficulty levels?**
A: Difficulty levels adjust the timing window for hitting notes:
- Easy: Generous window (±500ms)
- Medium: Balanced window (±250ms)
- Hard: Precise window (±100ms)
- Expert: Very precise window (±50ms)

**Q: Can I practice with sheet music?**
A: Yes, you can view sheet music alongside falling notes. Tap the sheet music icon to toggle display.

**Q: How do I improve my score?**
A: Practice regularly, start slow, use loop mode for difficult sections, and gradually increase tempo as you improve.

### Technical Questions

**Q: What Android version is required?**
A: Android 5.0 (API 21) or higher. MIDI support requires Android 6.0 (API 23) or higher for physical piano connection.

**Q: Can I export my recordings?**
A: Yes, recordings can be exported as MIDI files. Go to Progress Tracking → Select piece → Select recording → Export.

**Q: How do I backup my progress?**
A: Progress is stored locally. Use Android's backup feature or manually export recordings. The app doesn't sync to cloud.

**Q: Can I use PianoSync with other music apps?**
A: Recordings can be exported as MIDI files and used in other applications. However, real-time MIDI routing to other apps is not currently supported.

### Feature Questions

**Q: Can I change the key signature?**
A: Key signature is determined by the MIDI file. The app displays the key signature from the file.

**Q: Can I transpose songs?**
A: Transposition is not currently available, but may be added in future updates.

**Q: How many MIDI files can I import?**
A: There's no hard limit, but performance may be affected with very large libraries. The app displays up to 10 most recent files on the home screen.

**Q: Can I create my own MIDI files?**
A: You can import any standard MIDI file. To create MIDI files, use external MIDI editing software.
